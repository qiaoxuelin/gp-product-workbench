Google Play 商品工作台

帮助运营和开发团队批量维护 Google Play 一次性商品，减少重复录入；帮助财务按月下载原始收入报告。

主要功能

  • 多项目管理：按包名配置应用与授权，切换项目并记住上次访问的工作区。
  • 批量创建商品：复制现有商品，或导入 CSV / JSON 配置。
  • 地区改价：固定价格、百分比调整、Google 基准价换算；支持全部地区。
  • 多语言模板：勾选语言、下载模板、上传文案并预览；单个商品也可使用。
  • 销售状态管理：筛选草稿、启用、停用商品，批量调整购买选项状态。
  • 提交核对：本地草稿、差异预览、远端冲突检查、结果读回与未完成项核对。
  • 月度账单：下载 Google Earnings 原始收入报告，保留费用、税费、退款等明细。

首次使用

  1. 下载 Windows x64 ZIP，完整解压，双击“启动工具.cmd”。无需另装 Node.js。
  2. 可先在演示模式体验商品流程。真实使用时点击“＋ 新建项目”，填写项目名和 Android 包名。
  3. 在“连接设置”导入服务账号 JSON 并保存。授权准备见“如何准备 Google 授权？”或包内 GOOGLE_AUTH_GUIDE.html。
  4. 切换真实项目，读取商品。先用少量商品验证，再执行批量操作。

运行需要 Windows 10 / 11 x64、PowerShell 和浏览器；连接 Google 时需要网络。关闭浏览器不会停止服务，退出时双击“停止工具.cmd”。

日常操作

读取商品 → 编辑草稿 → 预览并提交 → 核对结果

  • 改价：勾选商品 → 批量改价 → 选择方式与地区 → 应用到草稿 → 预览提交。
  • 全部地区：CSV 的 regionCode 填 ALL，或在 Google 基准价换算时选择全部地区。同一购买选项不要混用 ALL 和具体地区行。
  • 多语言：首页或商品编辑页打开“多语言模板”，勾选语言并下载模板；填写后保存为 CSV UTF-8，上传时核对编码、内容和差异。目前不支持直接上传 XLSX。
  • 启用商品：新商品提交时选择“创建并启用”；已有草稿可勾选后启用，再预览并提交。“待提交”是本地修改，“草稿（未启用）”是远端销售状态。
  • 部分失败：在提交结果或操作记录中点击“核对未完成项”，重新读取远端，再生成预览并确认。

有勾选商品时，预览所选商品中的待提交项；没有勾选时，预览全部待提交项。编辑和导入只改本地草稿，确认提交后才写入 Google。

月度账单导出

  1. 切换真实项目，打开侧栏“账单导出”。
  2. 从 Play Console 财务收入报告栏目复制 Cloud Storage URI，粘贴并保存。
  3. 服务账号需具备账号级财务报告查看权限，详细步骤见账单窗口“首次配置与权限说明”。
  4. 选择年份和月份，读取账单并下载原始文件；同月如有补充调整文件，请一并核对。
地址配置一次即可。每个项目分别保存，刷新、重启和切换回来后仍保留。同一开发者账号下的多个项目可以填写相同 URI，但每个项目需各保存一次；更换账号或报告地址时再修改。

原始账单覆盖开发者账号全部应用，不按当前包名过滤。当前项目只用于选择授权和报告地址。工具不改写金额、不合并币种；收入报告不等同于银行到账凭证。

报告可能延迟发布，空列表不表示收入为零。下载列表 15 分钟后失效，重新读取即可；单文件超过 100MB 请从 Play Console 下载。

Google 官方财务报告说明

保存与升级

  • 项目、报告地址、授权与操作记录：免安装版保存在 %LOCALAPPDATA%\GP-Product-Workbench，独立于程序目录。源码版默认使用项目内 data 文件夹。
  • 本地草稿：保存在浏览器中。升级请继续使用原浏览器与 http://127.0.0.1:4318；清除站点数据会删除草稿。
  • 授权：JSON 使用 Windows 当前用户加密保存；可重新导入替换。换电脑或 Windows 用户需重新导入原始 JSON。
  • 升级：先停止旧版，再完整解压并启动新版。工具内“关于 PlayBatch”可查看当前版本。
  • 账单文件：保存在浏览器的下载位置，工具不会另存到账单缓存目录。

使用范围与反馈

目前支持一次性商品，不包含订阅、商品删除、商品图标、促销优惠管理、自动回滚或定时改价。财务功能提供原始报告，不生成自定义财务汇总或游戏内订单匹配表。

工具仅在本机运行；真实模式通过 Google 接口读写。提交后读回核对不等于游戏内购买验证，实际购买仍需在应用中测试。

遇到问题，请在 GitHub Issues 提供版本、步骤和错误文字，勿上传服务账号密钥或敏感账单。更详细的字段与操作说明见包内 README.md。
