# PlayBatch · Google Play 商品工作台

**面向 Google Play 一次性商品的 Windows 本地管理工具。**
批量创建商品、调整地区价格、上传多语言文案，在提交前集中核对差异，减少后台重复操作。

**[下载 Windows 免安装版](https://github.com/qiaoxuelin/gp-product-workbench/releases/latest)** · [查看版本更新](https://github.com/qiaoxuelin/gp-product-workbench/releases) · [反馈问题](https://github.com/qiaoxuelin/gp-product-workbench/issues)

由 [qiaoxuelin](https://github.com/qiaoxuelin) 开发与维护。v0.1.3 起，发布包统一使用 PlayBatch 名称；用户数据目录保持原位置，升级可继续使用已有配置。

适用于 Windows 10 / 11 x64。下载包内置运行环境，无需安装 Node.js；界面在本机浏览器中打开，连接 Google 时需要网络。

## 能做什么

| 场景 | 功能 |
| --- | --- |
| 管理多个应用 | 配置不同包名和授权，切换项目，记住上次访问的工作区 |
| 批量创建商品 | 从现有商品复制配置，或通过 CSV / JSON 导入 |
| 调整价格 | 固定价格、百分比调整、Google 基准价地区换算 |
| 覆盖全部地区 | CSV 中填写 `ALL`，或选择 Google 返回的全部地区 |
| 维护多语言 | 搜索勾选语言，下载模板、上传文案、预览差异；支持单商品入口 |
| 应用审核监控 | 按项目和发布轨道定时读取审核与发布状态，记录变化 |
| 财务月度对账 | 按月下载 Google Earnings 原始收入报告，保留费用、税费、退款等明细 |
| 管理销售状态 | 筛选草稿、已启用、已停用商品；批量启用或停用 |
| 核对提交结果 | 本地草稿、提交前差异预览、远端冲突检查、提交后读回与操作记录 |

> 当前管理的是 **一次性商品（one-time products）**，不包含订阅商品。

## 三步开始使用

### 1. 下载并启动

在 [Releases 下载页](https://github.com/qiaoxuelin/gp-product-workbench/releases/latest) 的 **Assets** 中下载名称含 `Windows-x64.zip` 的文件，完整解压后双击 **启动工具.cmd**。

浏览器会打开 [本机工作台](http://127.0.0.1:4318)。关闭浏览器不会停止后台服务，需要退出时双击 **停止工具.cmd**。

也可先切换到**演示模式**体验编辑与提交流程。演示操作不会写入 Google 商品，Google 地区换算仍需真实授权。

### 2. 配置项目与 Google 授权

点击 **＋ 新建项目**，填写项目名称和 Android 包名，导入 Google 服务账号 JSON 后保存。

授权准备分两部分：

1. 在 Google Cloud 准备服务账号 JSON，并启用 Google Play Android Developer API。
2. 在 Play Console 向该服务账号授予目标应用所需权限。

详细图文说明入口：工具内 **连接设置 → 如何准备 Google 授权？**；也可打开下载包中的 `GOOGLE_AUTH_GUIDE.html`。

每个项目可以配置自己的授权，也可以复用已获多个应用权限的服务账号。替换授权时导入新 JSON；留空则保留原凭据。当前不支持个人 Google 账号 OAuth 登录。

### 3. 读取、编辑、预览、提交

**读取商品 → 编辑本地草稿 → 预览并提交 → 核对结果**

编辑、改价和导入首先修改本地草稿。提交前会显示目标项目、包名和字段差异，核对并确认后才会请求 Google 写入。

有勾选商品时，预览范围是所选商品中的待提交项；没有勾选时，预览全部待提交项。

## 常用操作

### 批量创建与启用

- **复制创建**：勾选一个商品作为模板，每行填写一个新商品 ID。
- **CSV 导入**：点击“导入 CSV”下载模板，填写后上传。
- **新商品提交**：选择“创建并启用”或“仅创建草稿”。前者会在创建成功后执行启用，并读回核对。
- **已上传但未启用**：读取商品 → 筛选“草稿（未启用）”→ 勾选 → 启用 → 加入待提交 → 预览并提交。

“待提交”表示本地有修改；“草稿（未启用）”表示购买选项尚未启用。两类筛选可以组合使用。商品包含多个购买选项时，任一选项符合状态即会显示。

### 批量改价与全部地区

勾选商品后点击 **批量改价**，选择调价方式、币种、购买选项和目标地区。

Google 基准换算使用**税前基准价**，返回各地区价格；选择“全部地区”会添加缺少的地区，并将返回地区设为可销售。不同价格档位请分批操作；同一批换算商品需要使用一致的税务类别。

CSV 全部地区模板示例：

```csv
productId,purchaseOptionId,languageCode,title,description,regionCode,currencyCode,price,availability
coins_100,buy,zh-CN,100金币,购买后获得100金币,ALL,USD,0.99,AVAILABLE
```

同一购买选项不要混用 `ALL` 和具体地区行。不同商品可以填写不同基准价；特殊地区价格可在导入后单独调整。此功能不会修改应用本身的发行地区，也不会改写未来新地区的销售规则。

### 多语言模板

**批量入口**：首页“多语言模板”；勾选商品则处理所选商品，否则处理当前项目全部商品。
**单商品入口**：编辑商品 → 多语言模板。

1. 勾选需要追加的语言，下载 **Excel（.xlsx）模板**。
2. **每种语言一个页签**，名称是语言代码，例如 zh-CN、en-US、ja-JP。每页包含当前范围的商品，已有名称和描述自动填入。
3. 在对应页签填写名称和描述，保持页签名和第一行表头不变，保存为 .xlsx。
4. 上传工作簿，先查看各语言的记录数、空白跳过数和文案预览，再检查差异并应用。

Excel 每页三列：productId（商品 ID）、title（名称）、description（描述）。名称最多 55 个字符，描述最多 200 个字符。名称与描述都空的行会跳过，保留原有内容；只填一项会提示补齐。文案请使用文本，不支持公式、宏或加密文件。单个 XLSX 限 5MB、100 个语言页签及合计 50,000 行，超出请分批操作。

单商品导入会返回编辑表单，保留正在修改的价格等内容，再点击“保存草稿”完成。

旧四列 CSV 模板仍可上传：productId、languageCode、title、description。CSV 可选择编码；XLSX 直接保存 Unicode 文本，无需选择编码。两种格式都只更新列出的语言内容，地区和价格保持原样。商品配置的普通“导入 CSV / JSON”入口仍使用原格式。

### 月度账单导出

侧栏点击 **账单导出**，选择真实项目的授权，保存财务报告存储桶地址，然后选择年份和月份，点击“保存地址并读取该月账单”。

首次配置：

1. 在 Play Console → 下载报告 → 财务 → 收入报告（Earnings）旁点击“复制 Cloud Storage URI”。
2. 将 gs://pubsite_prod_rev_… 地址粘贴到工具。可保存到各项目配置中，同一开发者账号的项目可使用同一报告桶。
3. 由管理员在 Play Console 为该服务账号授予账号级、全局范围的查看应用信息/下载批量报告及查看财务数据权限。已有商品管理权限不一定能下载财务报告；此功能不需要退款操作权限。
4. 读取月份，下载原始 ZIP。若列出补充调整文件，请一并核对。

**原始账单覆盖开发者账号全部应用，不按当前包名过滤。** 当前项目只用于选择服务账号和报告地址。工具直接导出 Google 文件，不改写金额、不合并币种，也不将报告等同于银行到账凭证。

本版提供原始账单文件，不生成自定义财务汇总或游戏内订单匹配表。Google 报告通常包含 UTF-16 CSV，可用 Excel 打开。报表可能延迟发布；空列表不代表当月收入一定为零。单文件超过 100MB 时，请改从 Play Console 下载。

下载按列出时的对象版本读取，检查文件大小，并在 Google 提供 MD5 时核对校验值。下载列表 15 分钟后失效，重新读取即可。工具不将账单内容留存到自己的 data 目录；浏览器下载目录由使用者管理。

资料：[Google 官方月度报告和授权说明](https://support.google.com/googleplay/android-developer/answer/6135870?hl=zh-Hans)。

## 应用审核监控

打开侧栏 **审核监控**，独立选择监控项目、发布轨道和检查间隔，勾选启用后保存。支持 production、internal、alpha、beta，也可以添加自定义封闭测试轨道 ID。

- 后台服务运行时，每 5 / 15 / 30 / 60 分钟按项目独立查询一次；关闭浏览器不影响轮询，停止工具或电脑休眠期间暂停。
- 首次成功查询建立基线。后续记录“审核中、通过待发布、审核未通过、已发布”等状态变化，侧栏显示未读数量。工具内显示变化记录，也可配置飞书群机器人自动通知；目前不支持邮件。
- “通过待发布”需要开发者后续发布；“已发布”也可能包含分阶段或暂停后可恢复的版本，不代表全量发布。
- 空列表或某个版本从列表消失不等于通过或被拒绝。查询失败会显示错误，保留上次成功结果。
- 复用该项目服务账号，仅查询状态，不执行送审、发布或回滚。实际可见性取决于 Google 账号对目标应用的权限；真实账号接入需单独验证。

官方接口：[按轨道列出审核与发布状态](https://developers.google.com/android-publisher/api-ref/rest/v3/applications.tracks.releases/list)。

### 飞书群机器人通知

在 **审核监控 → 飞书通知** 中配置，按项目分别保存：

1. 飞书群设置 → 群机器人 → 添加机器人 → 自定义机器人，复制 Webhook。
2. 在工具中填入 Webhook；机器人启用签名校验时填写签名密钥。如使用关键词限制，请加入 **PlayBatch**。
3. 勾选“审核通过，等待发布”和 / 或“已经发布”，开启自动通知并保存。
4. 点击“发送测试通知到群”，在群内确认收到。测试按钮使用已保存的配置，测试消息会明确标注，不能当作过审结果。
5. 返回审核监控，确认该项目监控也已开启，保持本机后台服务运行。

Webhook 和签名密钥使用 Windows 当前用户加密保存，不在页面回显；留空保留，填写新值可替换。关闭机器人签名校验后可勾选清除已保存密钥。换电脑或 Windows 用户需要重新填写。

自动通知只处理启用后新检测到的状态变化，不补发此前的历史状态；首次审核查询仍仅建立基线。同一条已成功发送的事件不会在后续轮询或重启后再次发送。超时、中断等结果不明时不自动重试；先查看群消息，再在通知记录中手动确认重试，以免重复。失败与结果不明会保留记录。

消息包含项目、包名、轨道、版本及审核状态；不发送服务账号信息、商品明细或账单内容。不自动 @ 全体成员。目前一个项目对应一个群机器人，支持不同项目发到不同群。

[飞书官方机器人配置指南](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)。

## 常见问题

### 撤销草稿后为什么显示“无待提交修改”？

撤销后恢复到上次读取的配置，因此显示“无待提交修改”，不会向 Google 提交修改。“预览并提交”数量应相应减少。放弃全部草稿时会清除当前项目的草稿缓存；刷新后重新读取商品，不恢复已放弃的修改。


### 上传后文字乱码怎么办？

上传支持自动识别 UTF-8、带 BOM 的 UTF-16、GBK，并提供 GB18030、Big5 等手动编码选项。

自动识别不能覆盖所有情况。请核对导入预览；文字不正确时，返回切换编码，或从原始表格重新导出 **CSV UTF-8**。如果文件中的文字已经被替换成问号，切换编码无法恢复，需要找回原始内容。

### 商品已上传，为什么还未启用？

创建和启用是两个步骤。新商品提交时选择“创建并启用”；已经创建的草稿使用“启用”批量操作。提交结果会分别显示提交前核对、创建/更新、启用/停用、读回核对的结果。点击“核对未完成项”，工具会重新读取远端：已创建的商品只补做未完成状态变化，已全部完成的商品无需重试；远端出现其他修改时会阻止自动恢复。应用核对结果后仍需生成新预览并确认提交。

关闭结果窗口后，也可在“操作记录”中重新进入核对。旧版本真实操作记录不含项目标识，无法自动恢复，需要手动核对。

### 如何查看版本和升级？

侧栏与“关于 PlayBatch”显示当前版本。**侧栏 → 检查更新 → 更新并重启**，可从本仓库 GitHub 正式发布页下载新版，校验 SHA256 后安装并重启；下载进度和失败原因会显示在窗口中。

Windows 下检查到新版后可直接点击“更新并重启”。v0.1.10 起也支持从源码启动的工具：在原数据目录内安装独立发布版并切换，保留源码文件，原启动入口会跟随新版。v0.1.6 及更早版本需要先手动下载一次新版本。

新版安装在 %LOCALAPPDATA%\GP-Product-Workbench\versions（自定义 GP_DATA_DIR 时跟随数据目录）。只有新版启动并通过版本检查后，原来的“启动工具.cmd / 停止工具.cmd”才会切换到新版；旧程序目录不覆盖。启动失败时会尝试重新启动旧版，并显示结果。下载和切换过程中暂停其他写入操作。

项目配置、授权、账单地址和操作记录继续使用原数据目录；更新前会保存当前浏览器草稿。同一浏览器和本机端口刷新后可恢复草稿。旧版本与下载包暂不自动清理，会占用额外磁盘空间。不要删除当前使用的版本目录；如更新中断，可先运行原启动入口，再检查更新或手动下载。

也可点击“新版下载与更新说明”打开 GitHub 下载页。

### 升级会丢配置吗？

先停止旧版，再解压并启动新版。免安装版的数据保存在 Windows 用户目录：

```text
%LOCALAPPDATA%\GP-Product-Workbench
```

项目配置、加密凭据和操作记录独立于程序目录。**草稿保存在浏览器中**，请继续使用原浏览器及 `http://127.0.0.1:4318`；清除站点数据会删除该浏览器中的草稿。

### 授权文件保存在哪里？

服务账号 JSON 使用 Windows 当前用户加密后保存在本机。页面显示授权邮箱和保存状态，不回显私钥。换电脑或 Windows 用户时，请重新导入原始 JSON。

下载包和仓库不包含使用者的授权。请勿将自己的 JSON 密钥提交到仓库或附在问题反馈中。

## 导入、备份与使用范围

- CSV 按商品、购买选项、语言和地区合并，保留未列出的配置；CSV 本身不修改启用状态。
- 完整 JSON 导出适合商品配置备份；导入时包名必须与当前项目一致。
- 标签、税务、租赁、新地区规则等高级字段可通过完整 JSON 编辑。
- 暂不支持订阅商品、商品删除、商品图标、促销优惠管理、自动回滚和定时改价。
- 工具仅监听本机地址，不提供局域网访问。真实模式通过 Google API 读写商品。
- 提交前检查远端变化，但不具备跨工具的原子写入锁；批量操作时应避免同时修改同一商品。
- 读回核对不等于游戏内购买验证；Google 的价格、地区、权限和传播状态仍以实际结果为准。

## 从源码运行与验证

源码运行需要 **Node.js 22+ 和 Windows**；直接运行不需要安装 npm 依赖。

```powershell
npm start
```

也可双击 `start.cmd`，用 `stop.cmd` 停止。源码版默认使用项目内 `data/` 目录，与免安装版数据目录不同。

```powershell
# 核心与接口测试
npm test

# 浏览器测试，需要本机 Microsoft Edge
npm ci
npm run test:ui

# 构建 Windows x64 免安装包
powershell -NoProfile -ExecutionPolicy Bypass -File build-release.ps1
```

构建脚本下载并校验官方 Node.js，按文件白名单打包，不包含 `data/`、密钥、日志和浏览器草稿。

v0.1.4 增加财务报告测试，覆盖只读 OAuth、月份分页、文件完整性、原始字节下载与项目隔离；真实账单仍需在具备权限的账号上验证。

v0.1.3 的验证覆盖 CSV 编码和格式行号、提交步骤、失败后只补做未完成步骤，以及远端冲突拦截。接口测试包含模拟 Google 的创建、启用和读回顺序；自动化验证不替代真实应用的授权和购买测试。

## 反馈问题

请在 [Issues](https://github.com/qiaoxuelin/gp-product-workbench/issues) 提供版本号、操作步骤、预期结果和错误提示。涉及 CSV 时，可附不含业务敏感内容的最小样例，并说明导出软件和文件编码。

审核监控可独立选择项目，记住上次查看的监控项目，不改变商品页的项目、模式或草稿。飞书通知配置跟随审核监控中选择的项目；切换前有未保存的监控设置时会提示。

审核监控遇到版本查询配额超限（包括 quota 类 403、429）时，会保留上次成功结果，并按至少 15、30、60 分钟逐步延后重试；手动检查、保存配置及重启不会绕过冷却。界面显示下次允许查询的时间，不代表 Google 配额届时一定恢复。请在服务账号所属 Cloud 项目的 Google Play Android Developer API 配额页面核对用量；配额错误不应按缺少应用权限处理。
